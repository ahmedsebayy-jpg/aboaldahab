# ABO EL DAHAB — Premium Automotive Oils Website
# موقع أبو الدهب لزيوت السيارات

Official website for **Abo El Dahab** automotive oils and lubricants store in Faqous, Al Sharqia, Egypt. Designed with a premium dark automotive aesthetic inspired by Black Box Garage.

---

## 🚀 طريقة تشغيل الموقع على GitHub Pages في دقيقة واحدة

### الخطوة الأولى: رفع الكود على GitHub
أنشئ مستودع جديد (New Repository) على حسابك في GitHub، ثم نفّذ الأوامر التالية في الطرفية:

```bash
git add .
git commit -m "feat: Abo El Dahab website ready for GitHub Pages"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git branch -M main
git push -u origin main
```
*(استبدل `YOUR_USERNAME/YOUR_REPOSITORY` باسم حسابك والمستودع الخاص بك)*

---

### الخطوة الثانية: تفعيل الرابط المباشر من GitHub Pages
1. ادخل على المستودع الخاص بك على GitHub.
2. اضغط على تبويب **Settings** (الإعدادات).
3. من القائمة الجانبية اليسرى، اضغط على **Pages**.
4. تحت قسم **Build and deployment**:
   - في خانة **Source**، اختر: **GitHub Actions**.
5. اذهب إلى تبويب **Actions** ستجد أن GitHub بدأ البناء تلقائياً عبر ملف `.github/workflows/deploy.yml` المجهز في المشروع.
6. خلال دقيقة واحدة، سيظهر لك الرابط المباشر للموقع:
   `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/`
